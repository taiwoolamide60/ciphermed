# CipherMed Secure Medical Information Encryption System

## Description

CipherMed is a Python desktop application developed to demonstrate the use of classical cryptographic algorithms for protecting confidential patient medical information.

## Features

- Staff Authentication
- SQLite Database
- Caesar Cipher
- Additive Cipher
- Vigenère Cipher
- Encryption and Decryption
- Patient Record Management
- History Logging
- TXT Export
- PDF Export
- Professional GUI

## Technologies

- Python 3
- CustomTkinter
- SQLite
- ReportLab

## Running the System

1. Install requirements

pip install -r requirements.txt

2. Run

python main.py
